# Lookout

> Lookout is an endpoint-to-cloud cybersecurity company focused on mobile threat defense and data protection. Its Mobile Endpoint Security (MES) platform detects and responds to mobile-specific threats — phishing, smishing, malicious apps, network attacks, and device compromise — and exposes RESTful Mobile Intelligence APIs that stream threat, device, and vulnerability data into SIEM, SOAR, XDR, and MDM/EMM tooling.

This llms.txt was generated by the API Evangelist enrichment pipeline from the catalog profile and the provider's published documentation. Authentication is OAuth 2.0 client credentials (application key exchanged for a bearer access token, issued in the MES Console). All API endpoints are rate limited to 100 requests per minute per tenant.

## APIs

- [Mobile Risk API v2 overview](https://doc.lookout.com/en/mobile-endpoint-security/mes-apis/mobile-risk-api-v2/mobile-risk-api-v2-overview): Stream and query mobile threats, devices, OS, apps, and vulnerabilities. Base URL https://api.lookout.com/
- [Swagger API documentation](https://doc.lookout.com/en/mobile-endpoint-security/mes-apis/mobile-risk-api-v2/swagger-api-documentation): Interactive reference for the Mobile Risk API v2
- [Mobile Intelligence APIs](https://www.lookout.com/platform/mobile-intelligence-apis): SIEM/SOAR/XDR integration surface (Mobile Risk API, SSO Config API, Connector API, PCP Threat Feed)
